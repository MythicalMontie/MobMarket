*Mob Market is a lightweight utility mod designed to give homestead and farming packs a seamless way to give players a way to monetize surplus livestock.*

All players have to do is place down a Market Post. This will allow any (configured) mobs within the post's boundary to be sold each day when the configured market time rolls around. By default, only passive farm-type animals are configured.

### Features
**Completely Configurable:** You can configure just about anything from the sale time, the sale chance, down to if babies are allowed globally.

**Datapack Driven:** Currencies, allowed mobs, as well as prices are all set via datapack! This allows modpack developers to completely fine-tune the mod to fit their economy.

**Multi-Currency Support:** Supports multiple custom currencies simultaneously, allowing for tiered economic systems.

**Flexible Attribute Scalers:** Supports multiple modifier calculation types (linear, flat, exponential, and match), which allows prices to scale based on specific stats, attributes, or NBT tags.

**Built-In Mod Support:** Currently adds market posts for all wooded block types from BOP & BWG. Also hooks into FTB teams to allow the player's team/ally to open the market post if set to that access mode.
